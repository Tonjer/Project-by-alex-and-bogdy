## 🚀 Как запустить программу

### Вариант 1: Через IntelliJ IDEA (Рекомендуемый)

1.  **Клонируйте репозиторий:**
    ```bash
    git clone https://github.com/alex-and-bogdy/Project-by-alex-and-bogdy.git
    cd Project-by-alex-and-bogdy
    ```
2.  **Откройте проект** в IntelliJ IDEA (`File → Open`).
3.  Дождитесь индексации проекта.
4.  Перейдите в файл `src/main/java/consolehandler/Main.java`.
5.  Нажмите зеленую кнопку ▶️ рядом со строкой `public static void main` и выберите **Run 'Main'**.

---

### Вариант 2: Через терминал (Без IDE)
Подходит, если у вас установлена Java Development Kit (JDK), но нет IntelliJ IDEA.

1.  **Клонируйте репозиторий** (см. пункт 1 выше).
2.  **Скомпилируйте исходный код.** Убедитесь, что вы находитесь в корневой папке проекта:
    ```bash
    javac -d out src/main/java/consolehandler/*.java src/main/java/consolehandler/handlers/*.java
    ```
    *Эта команда создаст папку `out` со скомпилированными `.class` файлами.*
3.  **Запустите программу:**
    ```bash
    java -cp out consolehandler.Main
    ```
    *Флаг `-cp out` указывает Java, где искать скомпилированные классы.*

> **⚠️ Примечание:** Для работы программы требуется установленная JDK версии 8 или выше. Проверить версию можно командой `java -version`.
